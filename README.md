# Go Basics: 1-converter

Этот проект — простое приложение на Go для конвертации различных величин (например, температуры, длины, веса и т.д.).

## Как запустить

1. Убедитесь, что у вас установлен Go (https://golang.org/dl/).
2. Клонируйте репозиторий или скачайте исходный код.
3. Перейдите в директорию проекта:
   ```zsh
   cd 1-converter
   ```
4. Запустите приложение:
   ```zsh
   go run main.go
   ```

## Структура проекта

- `main.go` — основной файл приложения.
- Другие файлы могут содержать функции для конвертации различных величин.
